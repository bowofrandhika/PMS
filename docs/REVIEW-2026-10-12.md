## 2. Hal yang belum sesuai dengan dokumen requirement

Ini bukan bug, tetapi kekurangan terhadap Bagian 1–4 dokumen.

**Laporan dan export (Bagian 12)**
- Export **PDF sungguhan belum ada**. Yang tersedia: halaman cetak HTML (`format=print`) dan CSV. Export Excel `.xlsx` juga belum ada.
- Export CSV **tidak mencantumkan** waktu generate dan filter (syarat "data export harus … mencantumkan waktu generate/filter").
- Filter minimum belum lengkap. Yang ada: tanggal dan plan. Belum ada: shift, Work Order, Batch, equipment, status, pallet, user.
- Laporan belum ada untuk: Executive Dashboard (lengkap), Mandor Shift Report, Dryer Monitoring, MD Challenge, Consumable & Energy, Downtime & OEE (Pareto).
- Nomor dokumen dan revisi untuk controlled output belum ada.

**Dashboard dan alert**
- Belum ada alert. Yang ada hanya hitungan pending. Requirement meminta alert (sampling overdue, stok minimum, OEE INCOMPLETE, pola reject berurutan).
- `md_active_batch` masih `null` (placeholder).
- Alert pola reject berurutan per chamber sudah ada, tetapi hanya sebagai respons API saat input. Belum tampil di dashboard (MD-007, UAT-13).

**Dryer dan sampling (DRY-004, DRY-005)**
- Belum ada daftar *sampling task* yang dibangkitkan dari rule plan. Compliance hanya bisa dilihat lewat API `sampling-compliance`, tidak ada tampilan atau pengingat.
- Durasi downtime (DWT-001 "durasi dihitung sistem") belum ditampilkan.

**Consumable dan stok (CON-004, OI-08)**
- Saldo stok belum dihitung (receipt/issue/use/return/waste hanya dicatat).
- Alert `minimum_stock` belum ada (kolomnya ada, tetapi tidak dipakai).

**Pallet dan QC (PAL-004/005, QLT-003, Bagian 9.2)**
- Keputusan QC (`RELEASE_GOOD`, `REJECT_FINAL`, `KEEP_HOLD`) **tidak mengubah status pallet** maupun status Bale. Status `RELEASED` dan `SHIPPED` tidak pernah dipakai.
- Pemindahan pallet PARTIAL membuat status `MOVED`, sehingga Bale berikutnya masuk ke pallet baru. Ini perlu dikonfirmasi terhadap PAL-006 ("shift berikut melanjutkan, tidak reset").

**Keamanan dan operasional (Bagian 13)**
- Password policy yang configurable (AUTH-003) belum ada. Tidak ada wajib ganti password saat login pertama.
- Lampiran foto/PDF dengan batas ukuran belum ada.
- Prosedur restore dan uji restore belum ada (hanya skrip backup).

**UI dan usability (Bagian 13)**
- Tombol besar untuk MD dan Dryer (requirement Usability) belum dibuat khusus. Layar input masih form umum.
- Belum ada tampilan mobile untuk layar input cepat (requirement: mobile-friendly).
- Edit plan DRAFT dari UI belum ada (endpoint PATCH sudah ada).

**Pengujian (Bagian 15–16)**
- Tidak ada tes UI dan tes browser. 28 skenario UAT belum diotomasi. Pengujian saat ini adalah 21 tes API.
